Absence and Hypoplastic Disorders

Anatomy / Basic Science

Epidemiology

  • RLD: 1:30,000 (most common absent/hypoplastic), often bilateral
  • ULD: 1:100,000, usually unilateral
  • Central deficiency (cleft hand): 1:90,000
  • Transverse deficiency: 3:100,000
  • Phocomelia: < 1:1,000,000

Classification

Thumb Hypoplasia — Modified Blauth (Manske-McCarroll)

Grade Features Treatment
I Small but stable joints, adequate soft tissue Observation
IIA MCP UCL instability (uniaxial) Reconstruction (soft tissue)
IIB MCP multiaxial instability Chondrodesis consideration
IIIA Extrinsic tendon anomalies, stable CMC Reconstruction
IIIB Extrinsic anomalies, unstable/absent CMC Pollicization
IV Pouce flottant (vestigial digit) Pollicization
V Absent thumb Pollicization
  • CMC stability is the watershed — stable CMC = reconstruct; unstable/absent = pollicize
  • Tapered proximal MC base on XR = unstable CMC; flared base = some stability
  • FPL function inferred from well-developed IP joint crease
  • Pollex abductus (aberrant FPL-extensor connection) in 63% of type IIIA thumbs

RLD — Modified Bayne-Klug (Goldfarb)

Type Description
N Isolated thumb hypoplasia/absence
0 Type N + radial carpal anomaly
1 Shortened distal radius (> 2mm shorter than ulna)
2 Hypoplastic radius (miniature)
3 Partial absence of radius
4 Total absence of radius (most common, 27%)
5 Total absence + proximal humeral/glenoid deficiency

Central Deficiency — Manske Classification

  • I: Normal first web; II (A/B): Narrowed first web; III: Syndactylized first web; IV: Cleft merged with first web
  • Thumb/first web status prognosticates outcomes

ULD — Modified Bayne Classification

  • Type 0-5; Type 0 = normal ulna with ulnar hand anomalies; Type 4 = absent ulna with radiohumeral synostosis

Workup

RLD Associated Conditions (Must Screen)

  • VACTERL: ≥ 3 of vertebral, anal, cardiac, TE fistula, renal, limb anomalies (16:100,000)
  • Fanconi anemia: autosomal recessive, progressive bone marrow failure by age 5 (1:40,000) — chromosomal breakage studies mandatory
  • TAR syndrome: autosomal recessive, bilateral absent radii but thumbs always present, thrombocytopenia resolves
  • Holt-Oram syndrome: autosomal dominant, TBX-5 mutation, cardiac anomalies, higher prevalence of type 1 RLD
  • Workup: echo, renal US, spine XR, CBC, chromosomal breakage studies

Treatment

Thumb Reconstruction (Grades II-IIIA)

  • Surgery ideally after 18 months (lower anesthesia risk, hand doubles in size by 2.5 years)
  • First web deepening: four-flap z-plasty (most common); flap configuration CADB
  • Opponensplasty: ADM (Huber) — bulkier, better thenar contour; FDS — extra length for UCL reconstruction
  • UCL reconstruction: capsule-ligament-adductor flap advanced distally; FDS opponensplasty provides tendon for collateral augmentation
  • Extrinsic tendon reconstruction: FDS ring finger for FPL; EIP for EPL (if needed, second stage)

Index Finger Pollicization (Grades IIIB-V)

  • After 18 months; good prognosis if index pronates to pinch against long finger
  • Critical skin point: volar transverse limb just proximal to PIP crease
  • MC head = new CMC; PIP = new MCP; DIP = new IP
  • Digit positioned in 20° radial abduction, 40° palmar abduction, 90-150° pronation
  • MC head fully flexed to prevent CMC hyperextension
  • Preserve physeal artery to prevent growth arrest (decreased to 7% with technique adjustment)
  • Digit loss < 1%; revision rate ~25% (most commonly for opponensplasty)

RLD — Wrist Treatment

  • Treat wrist before thumb — radially deviated wrist limits thumb function
  • Passive stretching 5-10 min, 4x/day; night splint when arm is large enough
  • Centralization: carpus balanced on ulna, long finger aligned with ulna; K-wire fixation, ECU advancement
  • Soft tissue centralization: extra-capsular, avoids ulnar physeal injury — similar recurrence but better ulnar growth
  • Distraction lengthening: when stretching insufficient; 0.5-1 mm/day; complications in ≥ 50%
  • Vilkki procedure: vascularized 2nd MTP transfer — technically demanding, high complication rate

Central Deficiency

  • Close cleft (draw MCs together), create first web (Snow-Littler transposes cleft skin radially)

  • Extraperiosteal excision of transverse bones to prevent regrowth

  • Thumb hypoplasia teaching point: CMC stability determines reconstruction vs pollicization — stable CMC → reconstruct; absent or unstable CMC → pollicize

  • Parents often resist ablation of a vestigial thumb; connecting them with families post-pollicization helps the conversation — don’t rush the decision

Complications & Outcomes

  • Pollicization: outcomes affected by whether isolated thumb hypoplasia vs RLD; RLD patients have stiffer fingers and weaker grip
  • Centralization: average 36° radial deviation, ~50% forearm length, ~20% grip/pinch strength at 20-year follow-up; DASH scores variable
  • MCP instability is most common complication of thumb reconstruction (20/22 in one series regardless of technique)

Pearls / Pitfalls

  • Always screen for VACTERL, Fanconi, TAR, Holt-Oram in RLD — systemic conditions can be lethal
  • Fanconi anemia requires chromosomal breakage studies (not just CBC)
  • TAR: thumbs always present despite bilateral absent radii — distinguish from RLD type 4
  • Don’t pollicize if elbow has extension contracture (wrist flexion/radial deviation brings hand to face)
  • Ulnar prehension is a contraindication to pollicization (would preclude hand-forearm grasp)

Board-Style Questions (4)

  1. Q: A neonate has bilateral absent radii with intact thumbs and thrombocytopenia. What is the diagnosis? — A: TAR syndrome (thumbs are always present, distinguishing it from RLD type 4).
  2. Q: A child has Blauth grade IIIB thumb hypoplasia. What is the recommended surgical treatment? — A: Ablation and index finger pollicization — the unstable/absent CMC joint precludes reconstruction.
  3. Q: What genetic test must be performed in all patients with radial longitudinal deficiency? — A: Chromosomal breakage studies to evaluate for Fanconi anemia.
  4. Q: During pollicization, what is the critical skin landmark that determines thumb appearance? — A: The volar transverse limb must be placed just proximal to the PIP crease; too proximal makes the thumb look too long.
